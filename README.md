# SteamFrameMotherVRPatcher

SteamFrameMotherVRPatcher is a tool to patch MotherVR v0.8.1 to be compatible with the Steam Frame for standalone play.

**Version History**
- v1.0.0: First release version.

**Installation**

First download MotherVR v0.8.1 (https://github.com/Nibre/MotherVR/releases/tag/0.8.1) and extract the zip to a chosen folder.
Extract *SteamFrameMotherVRPatcher.exe* from the zip folder to the same folder and run it to patch MotherVR.
Copy the patched dxgi.dll and mothervr.json to the Alien: Isolation folder on your Steam Frame. Run the game via Steam as usual.
